# Lead Generation & Sales Architecture

## RFQ fields
Name, company, phone, email, project type, product, diameter, pressure/PN/SDR if known, PE grade if known, quantity, city, required date, BOQ upload, notes.

## Attribution
Store source, landing page, UTM, product, city, quantity, campaign and timestamp.

## Pipeline
New → Qualified → Contacted → Quoted → Negotiation → Won / Lost

## Metrics
- RFQs
- qualified RFQs
- datasheet/catalog downloads
- phone/messaging clicks
- lead→quote
- quote→sale
- organic-sourced revenue
- average RFQ value

## Pricing strategy
Build a **Price Intelligence Hub** explaining price drivers rather than publishing stale tables or hiding all pricing context.
