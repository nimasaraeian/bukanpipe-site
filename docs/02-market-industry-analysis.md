# Market & Industry Analysis

## Demand systems
- Water infrastructure
- Agriculture / irrigation
- Gas distribution
- Sewer / drainage where actual products support it
- Industrial fluid transfer where supported
- Laboratory / testing services

## What different buyers really buy
| Buyer | Core value |
|---|---|
| Contractor | lower project risk, availability, compliance |
| Engineer / consultant | technical confidence and documentation |
| Procurement | price, delivery, traceability, documents |
| Agricultural customer | reliable water transfer and lifecycle value |
| Public/infrastructure buyer | compliance and vendor reliability |
| Laboratory customer | credible testing, turnaround and reports |

## Commodity risk
The category naturally collapses toward price comparison. Bukan Pipe should reframe value around technical suitability, standards, quality evidence, traceability, project proof, response time and delivery confidence.

## Data policy
Do not publish invented or weakly sourced TAM/market-size numbers. Market-size figures must be current, traceable and authoritative.
