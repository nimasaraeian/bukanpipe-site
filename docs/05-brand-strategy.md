# Brand Strategy

## Positioning
**Engineering Trust for Infrastructure**

Working Persian line: **زیرساختی برای جریان فردا**

## Personality
- Engineer: precise, rational, technical.
- Builder: industrial, capable, dependable.
- Advisor: helps buyers choose correctly.

## Avoid
- unsupported “best in Iran” claims
- generic stock imagery
- empty “advanced technology” claims
- excessive promotional adjectives
- luxury/SaaS-like styling

## Proof architecture
| Weak claim | Preferred proof |
|---|---|
| High quality | named test + standard + evidence |
| Advanced technology | real equipment/process/photo |
| Trusted | documented project/case study |
| Export success | market/year/document |
| Accredited lab | valid certificate + scope + dates |

## Visual direction
Real imagery from production, QC, lab, pipe marking, storage, loading and projects.
