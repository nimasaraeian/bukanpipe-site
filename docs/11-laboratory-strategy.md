# Laboratory Strategy

The laboratory should be both:
1. a trust engine for pipe sales
2. an independent inbound acquisition channel

Proposed structure: `/laboratory/`, accreditation, services, tests, request-test.

Potential test topics discussed: OIT, hydrostatic, MFI, carbon black, density, dimensional testing — **only if present in the verified current scope**.

Before publication verify accreditation status, certificate ID, issuing authority, validity, scope and actual customer availability.
